Calendar & Health is a personal widget for Scriptable on iPhone.
it’s show Health stats from a companion Shortcut

🔗Requirement : 
iPhone with Scriptable installed
iCloud Drive enabled for Scriptable
Apple Shortcuts for Health sync
Calendar permissions.

🔗install : 
Download or copy Calendar & Health Script.js
Open Scriptable.
Create a new script.
Paste in the contents of Calendar & Health Script.js
Name the script Calendar & Health Script.
Add a Medium Scriptable widget to your Home Screen.
Set the widget script to Calendar & Health Script.
Run the script once inside Scriptable to open settings and initial setup.

🔗Health Sync : 
Calendar & Health Script reads health data from:
iCloud Drive/Scriptable/Calendar & Health Script.json
